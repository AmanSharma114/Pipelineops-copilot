# Water Quality Monitor handbook
Version 1.0

## Trigger and schedule
The reference schedule checks the probe gateway every fifteen minutes for a sealed export. A manifest declares one probe, the expected calibration revision, and the first and last sample sequences.

## Report consumers
Telemetry Operations reviews the turbidity range and unique sample count for each accepted export. Values are expressed in nephelometric turbidity units (NTU). The report describes sensor telemetry and makes no determination about drinking-water safety.
