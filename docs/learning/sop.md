# Learning Completion Sync operating procedure
Version 1.0

## Safe restart
Preserve the original export and inspect the rejected learner-course pair. Obtain a corrected export from Learning Systems, then rerun learning_sync. Publish the replacement register only after a successful batch exit.

## Verification
Sort the register by learner and course. Confirm the latest revision survives an out-of-order delivery. In the sample, L-09 finishes LAB-101 at revision 2 with status completed.
