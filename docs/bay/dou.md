# Bay planning support agreement
Version 1.0

## Support ownership
Yard Planning owns Bay Planner and approves capacity corrections. Dispatch Operations confirms the published snapshot ID. A yard supervisor verifies corrected capacity before the planner retries the affected yard date.

## Handoff to gate support
After release, send Gate Operations the yard date, plan ID, and assignment count. When a plan is delayed, communicate the last released plan ID so gate reconciliation can distinguish old and new assignments.
