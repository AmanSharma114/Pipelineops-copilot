# Departure monitoring support agreement
Version 1.0

## Support ownership
Gate Operations owns Departure Monitor and approves replay of gate event batches. Yard Planning confirms the released bay plan and bay assignment. The transport desk owns communication about delayed departures.

## Unmatched event handoff
Send Yard Planning the plan ID, route ID, bay ID, and gate event timestamp. Gate Operations keeps the event pending until Yard Planning verifies the assignment. Preserve the captured gate timestamp throughout recovery.
